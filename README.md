# SectorOps

Browser-first 3D shooter prototype for a realistic, milsim-inspired tactical game.

## Stack
- Vite
- TypeScript
- Babylon.js

## Run
1. Install dependencies
2. Run `npm run dev`

## Share a Link
1. Push the repo to GitHub.
2. Enable GitHub Pages in the repository settings.
3. Use the GitHub Actions workflow in `.github/workflows/deploy.yml` to publish the site.
4. Share the Pages URL with friends.

## Prototype goals
- Medium-scale 3D map
- Responsive first-person movement
- Realistic weapon handling baseline
- Future P2P multiplayer foundation
